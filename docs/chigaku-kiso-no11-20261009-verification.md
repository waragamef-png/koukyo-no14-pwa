## 手書き・図の確認と出題方法

| 箇所 | 確認結果と出題上の扱い |
| --- | --- |
| 地下の岩石の溶融 | 手書きはマグマ。マントル全体が常に液体であるとはしない |
| 発生場所 | 海嶺・ホットスポット・島弧－海溝系の三つ |
| マントルの岩石 | かんらん岩。鉱物名のかんらん石と区別して採点する |
| とけやすい成分 | 部分溶融。岩石全体の完全な溶融とは区別する |
| 左側の図 | 縦軸は温度、横軸は圧力。手書きの深さも読み取った。圧力は深さと関係する |
| A・B・C | Aは温度上昇、Bは圧力低下、Cは水を含む場合の溶融開始温度の低下 |
| 海嶺・ホットスポット | 減圧による溶融が重要。「実際のマグマには水分が一切ない」という絶対的な設問にはしない |
| 沈み込み帯の水 | 海洋プレートの岩石などに含まれる水が深部で放出され、上側のマントルへ供給される。海水がそのまま水路を流れ込むとはしない |
| 低温でマグマができる | 乾燥した場合との比較。0℃などの日常の低温を意味しない |
| マグマだまり | 手書きはマグマだまり。浮力で上昇し、密度差の減少などで滞留する教材の説明を確認。滞留の原因が密度差だけに限定されるとはしない |
| 結晶分化作用 | 晶出した鉱物と残った液体の組成が異なることが重要。結晶が残液から分離することも解説に補った |
| 分化系列 | 玄武岩質→安山岩質→デイサイト質→流紋岩質。教材の代表的なモデルと限定し、実際の全てのマグマに必須の過程とはしない |
| デイサイト質 | 手書きの名称を確認。デーサイト・ダサイト・石英安山岩など確認できる呼称も入力候補に登録 |
| 有色鉱物 | かんらん石→輝石→角閃石→黒雲母。代表的な反応系列として出題 |
| 無色鉱物 | Caに富む斜長石→Naに富む斜長石。カリ長石と石英は低温側であり、両者の前後を全条件に共通の固定順序とはしない |
| 枕状溶岩 | 海底などで玄武岩質溶岩が水に急冷されてできる枕状の形を確認 |
| 熱水噴出孔 | 原本の「枕の割れ目の部分は熱水噴出孔とも呼ばれる」は、全ての割れ目をそう呼ぶと読めるため、そのまま正解にはしない。熱水が出る場所と溶岩の形を区別して出題した |
| 火山フロント | 火山分布の海溝側の境界を結ぶ線。手書きの100km〜200kmを、何の距離かを限定せず固定的な数値問題にしない |

## 照合先

- [東京大学地震研究所: マグマの発生](https://www.eri.u-tokyo.ac.jp/TAK-LAB/general/phenomena/generate.html): 部分溶融、圧力低下に伴う溶融、密度差による上昇。
- [気象庁: 火山噴火の仕組み](https://www.jma.go.jp/jma/kishou/know/whitep/2-4.html): 沈み込むプレートが運び込む水、融点の低下、海溝と火山分布、火山フロント。
- [文部科学省: 地震火山観測研究計画の用語解説、マグマ](https://www.mext.go.jp/b_menu/shingi/gijyutu/gijyutu6/toushin/attach/mext_01026.html): 沈み込み帯の水、密度の釣合いとマグマだまり、結晶分化。
- [産総研 地質調査総合センター: 岩石や地層のでき方](https://www.gsj.jp/geology/fault-fold/formation/R-formationJ.html): マグマ・鉱物の関係、有色鉱物の代表的な反応系列。
- [北海道大学の教育資料: 地質学](https://hosho.ees.hokudai.ac.jp/tsuyu/top/dct/rock-j.html): かんらん岩、分別結晶作用、Ca/Na斜長石、玄武岩・安山岩・石英安山岩・流紋岩の系列。
- [JAMSTEC: 枕状溶岩で海洋地殻を読み解く](https://www.jamstec.go.jp/j/pr/topics/jamstec-eye-20230523/): 水による急冷、表面の固結と再流出による枕状溶岩の形成。
- [地震本部: 海嶺](https://www.jishin.go.jp/resource/terms/tm_ridge/): 枕状溶岩と、熱水噴出により形成されるチムニーの区別。
- [地震本部: 火山フロント](https://www.jishin.go.jp/resource/terms/tm_volcanic_front/): 火山分布の海溝側の境界。手書きの距離を過度に一般化しないための照合。
