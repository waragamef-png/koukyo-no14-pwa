# 授業プリント学習アプリ

授業プリントや過去問を見ながら、地学基礎・公共・英文法・地学入門・日本国憲法の要点確認・暗記カード・問題演習ができるPWAです。

公共はNo.8-19を収録しています。2026年10月7日の追加資料（No.14-19）は `koukyo-20261007.js` にまとめ、重複する旧No.14は画面上で統合しています。解答の照合記録は `docs/koukyo-20261007-verification.md` を参照してください。

地学基礎はNo.12-16の7ページを収録し、以前の地学入門とは別に選べます。データは `chigaku-kiso-20261008.js`、手書き解答・計算の確認記録は `docs/chigaku-kiso-20261008-verification.md` にあります。数値問題は小数点・符号・単位を保って採点します。

## iPhoneで使う

1. GitHub PagesのURLをSafariで開く。
2. 共有ボタンを押す。
3. 「ホーム画面に追加」を選ぶ。
4. 追加したアイコンから起動する。

ホーム画面から起動すると、PWAとして単独画面で表示されます。初回表示後は主要ファイルがキャッシュされます。

## ローカル確認

```powershell
python -m http.server 5173
```

ブラウザで `http://127.0.0.1:5173/` を開きます。
